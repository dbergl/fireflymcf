# Derived slots on 14.7 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `options.derived_slots` computes the slots 14.7's GuiCode derives from the coach's options (11, 12, 319), as it does 13.6's (6, 453), so a 14.7 owner's settings need not name slot 11 by hand, and 14.7 renders draw the right battery card and nav rail.

**Architecture:** `derived_slots` becomes per-firmware: a table per located image (13.6, 14.7) of target slots, source slots and the rule, each guarded by a byte check of the GuiCode routine it transcribes. An image whose routine bytes do not match derives nothing. `livecfg`'s count-selector map becomes per-firmware too (14.7's Go Power! count is slot 95, not 39).

**Tech Stack:** Python 3, capstone (already a dependency), pytest.

**Spec:** none written; owner approved the design in chat 2026-11-10 (this plan's Goal and the evidence below). Rulings without a spec are provisional.

## Evidence (14.7 GuiCode, maps at 0x00240000; `fireflymcf slot-source` lists every store)

Slot registers: 11 = `0x20039BF5`, 12 = `0x20039D9D`, 319 = `0x2003A14F`, 33 (AGS/AES selector, OPTIONS "AGS"/"AES"/"AES Single Output") = `0x20039F08`, 95 (Go Power! count) = `0x2003A037`, 104 (Progressive Inverter) = `0x2003A169`, 105 (Lithionics Batteries) = `0x2003A009`.

```
0x0024A12E ldr r3,[pc,#0x120] ; =0x2003A009 (lit @0x24A250) Lithionics (105)
0x0024A130 ldrb r3,[r3] ; cmp r3,#0 ; beq.w 0x24A2FC
0x0024A138 ldr r3,[=0x20039BF5] ; movs r2,#3 ; strb  -> slot 11 = 3   (store @0x24A13C)
0x0024A2FC ldr r3,[=0x20039F08] (lit @0x24A544) ; ldrb ; cmp r3,#1 ; beq 0x24A30C
0x0024A304 ... movs r2,#0 ; strb @0x24A308 -> slot 11 = 0 (lit @0x24A548)
0x0024A30C ... movs r2,#2 ; strb @0x24A310 -> slot 11 = 2
0x0024A13E ldr r3,[=0x20039F08] ; ldrb ; subs #2 ; uxtb ; cmp #1 ; bls.w 0x24A314
0x0024A14C ldr r3,[=0x20039D9D] ; movs r2,#1 ; strb @0x24A150 -> slot 12 = 1
0x0024A314 ldr r3,[=0x20039D9D] ; movs r2,#0 ; strb @0x24A318 -> slot 12 = 0   (33 in {2,3})
0x0024A170 ldr r3,[=0x20039F08] ; ldrb ; cmp #0 ; bne.w 0x24A33A
0x0024A17A ldr r2,[=0x2003A037] ; ldrb ; cmp #0 ; bne.w 0x24A33A          (Go Power! count)
0x0024A184 ldr r2,[=0x2003A169] ; ldrb ; cmp #0 ; bne.w 0x24A33A          (Progressive Inverter)
0x0024A18E ldr r3,[=0x2003A14F] ; strb r2 (=0) @0x24A190 -> slot 319 = 0
0x0024A33A ldr r2,[=0x2003A14F] ; movs r1,#1 ; strb @0x24A33E -> slot 319 = 1
```

Slot 95 is the Go Power! count: the same clamp setter as 13.6 at `0x002477D0` (`cmp r0,#5; bhi`, store `0x002477DE`) and the same config-payload byte `+0x0B` stored at `0x00247D06` (13.6: `0x00247C50`, slot 39).

Readers (`options._switch_readers` on 14.7): slot 11 → base 765, values {0,1,2,3}, no default arm (value 1 is never written: unreachable). Slot 12 → base 428 {1, default}, a base slot 33 also reads. Slot 319 → base 343 {0,2,4, default} (as 13.6's 453: 0 the four-icon rail, else the default; 2 and 4 unreachable).

So, on 14.7: `slot 11 = 3 if L else (2 if A == 1 else 0)`; `slot 12 = 0 if A in (2, 3) else 1`; `slot 319 = 1 if (A or G or P) else 0`, with L = slot 105, A = slot 33, G = slot 95, P = slot 104.
